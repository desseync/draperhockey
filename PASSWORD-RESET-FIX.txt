DRAPER COMMAND — PASSWORD RECOVERY FIX

What this patch does
--------------------
Netlify Identity's default reset-password email returns to the site's root URL
with a #recovery_token=... hash fragment. The public homepage previously did not
load a callback handler, so the token appeared in the address bar but nothing
processed it.

This patch loads Netlify's official Identity widget on the homepage. It stays
invisible during normal visits. When Netlify sends a recovery/invite/confirmation
hash token, the widget can process the callback and show the appropriate Identity
flow.

After deployment
----------------
1. Request a NEW reset-password email in Netlify Identity.
2. Open the new email link.
3. DraperHockey.com should now display the Netlify set-new-password flow.
4. Set the password.
5. Go to https://draperhockey.com/command/ and sign in with the new password.

Security note
-------------
Do not reuse a recovery token that has been pasted or shared. Request a fresh
reset email after this patch is live.
