DRAPER COMMAND V2.1 — MANUAL ACTION ORDERING

Adds persistent manual ordering for Actions.

Desktop:
- Go to Actions.
- Drag an action up/down by its drag handle.

Phone / touch:
- Use the ↑ and ↓ buttons.

The new order is saved to the existing Netlify Blobs data automatically.
No data import is required and existing Command Center data is preserved.
